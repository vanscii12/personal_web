# 看板设计风格

看板（`dashboard_template.html` → `results/dashboard.html`，含回测页、数据页）的视觉和交互约定；加页面、加图表时照着做。
风格沿用 `E:\Personal-Web`，tokens 取自它的 `src/index.css`（那边 CLAUDE.md 里写的 Cormorant Garamond、`#EBE9E1` 是旧版，不作数）。
以模板为准：本文和代码对不上时，按代码改本文。

## 基调

- 安静的档案目录：亚麻底、暖灰墨色、少量 sage 点缀。只有浅色（`color-scheme: light`），和 Personal-Web 一样不做深色模式。
- 层次靠细线和底色深浅，不靠阴影：卡片只有 1px 边框，阴影只给浮层（提示框、下拉列表）。不用渐变、图标库和 emoji，
  图标用字符（→ ↗ ✓ × + ⚠ ↓ ↑），唯一的 SVG 是下拉框的 chevron。
- 数据优先：数字一律等宽、右对齐；图表细线、不做动画；颜色只用来区分系列和正负，不做装饰。
- 动效轻，只在换页时播放；同一页里的切换（排序、对数 / 线性、换基准）直接重画。
- 单文件、不构建：样式和脚本都写在模板里，外部只有 Google Fonts 和 jsDelivr 的 ECharts 5.5.1（离线时图表位置给出提示，表格照常）。

|---|---|---|---|

| `--surface` | `#F7F3EE` | 卡片、数字卡、提示框、下拉列表 | |

| `--sage-light` | `rgba(139,154,123,.12)` | 行悬停底色、输入框焦点光晕 | |

- `--muted` 不到 4.5:1（沿用 Personal-Web 的值），只放辅助信息；必须读的内容用 `--fg-soft` 以上。
- `--sage` 只做点缀和填充，不当文字色，sage 色的字用 `--sage-ink`。选中 pill 是 sage 底 + surface 字（2.71:1，沿用 Personal-Web），
  所以 pill 里只放短标签。
- ECharts 读不到 CSS 变量，脚本里另有一份：`INK`（同名墨色，外加坐标轴线和成交额柱用的 `axis: #C9C1B4`）和 `PALETTE`。改颜色两边一起改。
- 与 Personal-Web 的对应：`--color-bg-linen` / `--color-photo-border` / `--color-fg-charcoal` / `--color-fg-muted` /
  `--color-accent-sage(-light)` / `--color-border-warm` → `--bg` / `--surface` / `--fg` / `--muted` / `--sage(-light)` / `--border`；
  `--fg-soft`、`--sage-ink`、`--grid`、`--pos` / `--neg`、`axis` 是看板加的。

### 数据配色

分类色 `PALETTE`，8 个槽，顺序固定：

| 槽 | 色 | | 对 `--surface` 对比度 |
|---|---|---|---|
| 0 | `#3f72af` | 石板蓝 | 4.49 |
| 1 | `#c2603a` | 陶土 | 3.78 |
| 2 | `#2f8f6f` | 青绿 | 3.60 |
| 3 | `#a97a10` | 赭黄 | 3.47 |
| 4 | `#9b4f8e` | 梅紫 | 4.87 |
| 5 | `#5e8b2e` | 橄榄绿 | 3.65 |
| 6 | `#6a5bc2` | 靛紫 | 4.89 |
| 7 | `#b8423f` | 砖红 | 4.89 |

在 surface 上用 dataviz 的 `validate_palette.js` 校验过（模板注释：色盲模拟下两两 ΔE ≥ 8.6，正常视觉 ≥ 15.7，对比度 ≥ 3:1）；
对 `--bg` 的对比度最低也有 3.23。

- 谁用哪个槽：
  - 对比页：每个选中的回测占一个槽，选中期间不变；取消后空出，新选的从最小的空槽起；最多 8 个。
  - 策略页：按参数排序后的顺序取色（超过 8 组的画成灰色）。
  - 单次回测页：已选入对比的用自己的槽，否则槽 0；参照（如 `ew`）依次取后面的槽。数据页的价格和回撤用槽 0。
  - 基准永远是 `--muted` 灰、线宽 1.5、垫在最底层；表格里基准行是灰字、放最后。
- 正负：月度 / 年度收益表和相关矩阵的格子底色 = `rgba(var(--pos 或 --neg), min(|v| / scale, 1) × 0.5)`，scale 为
  月 8%、年 30%、相关 1；最深时炭黑字的对比度仍 ≥ 6.4:1，字不换色。不用红 / 绿：红绿色盲分不开，A 股和美股的涨跌色也正好相反。
- 持仓时间线（热力图）：只做多时用单向蓝 `#DCE5EF → #3f72af → #1f4677`（越深权重越高）；有空头时用 `#c2603a ← #EFEAE2 → #3f72af`。
- 新颜色先校验：图形 ≥ 3:1、文字 ≥ 4.5:1（对 `--surface`），分类色还要过色盲 ΔE。

## 数字与文字

- 百分比默认 1 位小数（`12.3%`），超额带正号（`+1.2%`），年成本 2 位；比率 2 位（夏普 `1.05`）；换手 `4.2×`；净值终点 `2.35×`；
  成本设置写 bp（`佣金 10bp`）。
- 负号用 "−"（U+2212，`minus()`），缺值写 "—"。
- 日期 ISO（`2025-12-31`）、等宽；区间写 `2011-08 → 2025-12`。
- 大数用 万 / 亿（`big()`），价格最多 6 位有效数字（`px()`）。
- 分隔用 " · "；"→" 表示去向（面包屑、`对比所选 3 个 →`、`改参数再跑 →`）；"↗" 新窗口打开；"✓" 已选；"×" 移除；"+" 新建 / 添加；
  "⚠" 读不出的脚本；列头的 "↓ / ↑" 是排序方向。
- 语言：导航、面包屑和固定页面的大标题用英文（导航 `strategies`，面包屑 `backtests → compare`，标题 `Compare`），其余界面文字用中文；
  代码、参数名、run id、命令原样照写，用等宽。
- 标的池基准显示成"<池名> 等权"（meta 里是 `universe:<池名>`）。
- 卡片标题短（净值、回撤、年度收益），口径写在右边的 note 里（相对历史高点、首末年为部分年份）。
- 空状态是灰色斜体的 `.empty` 段落，写明下一步（如运行 `python run_all.py`）；要 server.py 的页面从 file:// 打开时给出启动命令和地址。
- 按钮不可用时换成说明文字（`在策略页勾选参数组后对比`），不只是置灰。

## 布局

以下尺寸单位都是 px。

- 骨架：左上角固定品牌（top 32、left 48），左侧垂直居中的固定导航（left 48，项间距 32）；主体
  `margin-left: max(152px, (100% - 1240px) / 2)`，最宽 1240、内边距 96 / 48，宽屏居中并避开导航。
- 每页头部用 `header(label, title, subline)`：面包屑 → h1 + "." → 灰色副标题 → 1px 分隔线；接着一行 pill（`.filters`，右侧可放 CTA），
  再往下是列表或卡片。
- 间距：卡片之间 24，筛选行和分隔线下方 32，卡片内边距 20 / 22，列表行内边距 14 / 16。
- 圆角：pill、CTA 20（胶囊）；卡片、数字卡、下拉列表 10；搜索框和它的结果浮层 8；列表行、输入框、提示框、日志 6；勾选框、焦点框 4。
- 栅格：
  - 策略列表一行：名称 `minmax(240px, 1fr)`、区间 128、6 个指标各 72、箭头 14；参数组页前面再加勾选框（22）和 `--params` 个参数列。
  - 数字卡 `repeat(auto-fill, minmax(150px, 1fr))`、间距 16；表单 `minmax(220px, 1fr)`；双栏卡片 `.grid2` 1fr 1fr、间距 24。
  - 图表高：常规 360、回撤 220、价格 440；持仓时间线每行 16。
  - 宽表格包 `.scroll-x` 横向滚动，页面本身不横向滚动。
- 断点：
  - ≤ 1100：列表去掉区间、换手、成本三列；双栏变单栏。
  - ≤ 760：品牌和导航回到页顶（导航横排）；主体内边距 32 / 16 / 64；h1 32；列表只留年化、最大回撤；卡片内边距 16 / 14；
    搜索结果去掉时段列。

## 组件

- **pill** `.tag-pill`：12px、内边距 4 / 14、`--border` 边框、灰字；能点的 pill 悬停和选中都是 sage 底 + surface 字，纯标签不变。
  `.sm`（11px）用于行内标签和卡片头的开关，`.ghost`（虚线）用于"+ 添加"和读不出的脚本，禁用 45% 透明。用在：类型 / 标签筛选、
  区间预设（全部 / 近 10 / 5 / 3 / 1 年）、开关（基准、对数 / 线性、全收益 / 未复权）、`# 标签`、页面上的链接组。
- **CTA** `.cta`：等宽 12px、炭黑描边胶囊，悬停反色；`.primary` 实心炭黑、悬停变 sage；`.off` 灰框不可点。
- **列表行** `.run-row`（Personal-Web 的 note-row）：圆角 6；悬停 sage-light 底、右移 4px、末尾 sage "→" 淡入；整行可点，
  行内链接和勾选框各管各的。多组参数的指标格上面是最高值、下面灰色小字是最低值。
- **列头**：11px 灰色按钮，当前排序列变炭黑并带 ↓ / ↑；第一次点，文字列升序、数字列降序。
- **勾选框** `.check`：16px、1.5px 灰框、圆角 4；选中填炭黑、surface 色的勾（留了 `--slot` 变量，目前没设）。
- **卡片** `.card`：surface 底、1px 边框、圆角 10；`.card-head` 左边 h2，右边 note 或开关，基线对齐。可折叠的用 `details.card`，
  标题后跟 sage 色的" +" / " −"。
- **数字卡** `.tile`：灰色标签 → 26px 大数 → 灰色小注（`基准 9.8%`、`索提诺 1.12`）；放这一页的头条指标。
- **表格**：表头 11px 灰、右对齐、下边 `--border`；数字格等宽 12.5px、右对齐、行线 `--grid`，最后一行无线；文字列 `.left`，
  名称列 `td.name`（Inter 13px，可换行）。`.heat` 格子之间留 2px surface 缝、按数值上底色；`.fit` 是不撑满的矩阵（相关性）。
- **色块** `.key`：14×2 的短线，和图例（14×2）、提示框（12×2）一样都是线段，表格的行靠它对上图里的线。
- **meta 行**：等宽 12px 灰字，关键值加粗（fg-soft、500）。**信息表** `dl.info`：两列，dt 灰、dd 等宽 12px。
- **表单**：字段名 fg-soft 500，后跟灰色等宽的 flag；输入框等宽 13px、`--bg` 底、1px 边框、圆角 6；焦点 = sage 边框 + 3px sage-light
  光晕（不用 outline）。下拉框画成输入框的样子、带灰色 chevron；浏览器支持 `appearance: base-select`（Chromium）时，展开的列表也自己画：
  surface 底、圆角 10、柔和阴影、sage-light 悬停、sage-ink 的勾、分组标题 11px 字距 1.5px，value 以 `+` 开头的动作项（新建标的池、
  单个标的）放在最下面、用细线隔开。复选框 `accent-color: sage`。
- **搜索框**：等宽 14px、surface 底；筛选行里的 `.drop` 版是 12px 胶囊，结果浮在下面。结果行：代码（等宽）/ 名称 / 类型 pill /
  时段（灰）；↑ ↓ 选，Enter 打开。
- **日志** `pre.log`：等宽 12px、`--bg` 底、边框、超过 380px 滚动。
- **警告** `.warn`：陶土色 12.5px；失败的状态 pill 是陶土色边框和字。
- **链接**：说明文字里的 `.linkish` 是 fg-soft 字 + sage 下划线；表格和列表里的链接平时不带下划线，悬停出 sage 下划线。
- 焦点 `:focus-visible`：1.5px sage 描边、偏移 2px。选中文字：炭黑底、亚麻字。
- 浮层阴影只有三种：提示框 `0 8px 30px rgba(0,0,0,.06)`（= Personal-Web 的 `--hover-shadow`）、搜索结果 `0 8px 30px rgba(0,0,0,.08)`、
  下拉列表 `0 16px 40px rgba(44,44,44,.10), 0 2px 6px rgba(44,44,44,.05)`。

## 图表（ECharts）

- 共用：折线用 `lineChart`，其他图用 `mount` 加 `axisLabel`、`tooltipBox`；`animation: false`、canvas；换页时 dispose，窗口缩放时 resize。
- 网格 `containLabel`，左 8、右 16（有终点标签时 52）、上 40（留给图例）、下 4。
- 图例在左上：14×2 线段、间距 18、12px fg-soft。
- 坐标轴：x 是时间轴，轴线 `#C9C1B4`，无刻度、无竖网格；y 无轴线、无刻度，横网格 `--grid` 1px 实线；标签等宽 11px 灰，重叠就隐藏。
- 线：宽 2（基准、参照 1.5），圆头圆角，不画点，LTTB 抽样，关掉 emphasis；主线在上，基准垫底。
- 提示框：按轴触发，1px 灰色竖线；surface 底、1px 边框、圆角 6、内边距 8 / 12；内容是日期（等宽 11px 灰）+ 每行"色块、数值（等宽 600）、
  名称（fg-soft）"。
- 净值：起点 = 1；默认对数轴（底 2，可切线性），对数轴下限 = 最小值 × 0.97、线性轴不从 0 起，标签 3 位有效数字；≤ 4 条线时终点标 `2.35×`。
- 回撤：百分比轴、上限 0、标签取整；单次回测页和数据页的主线加 10% 透明度的面积（多条线的对比页、策略页不加）。
- 持仓时间线：热力图，一行一个标的（持有最多的 30 个；多标的按周取最后一个交易日），x 轴只在每年第一个交易日标年份；悬停描炭黑边，
  点色块进标的页。
- 价格图：上下两个网格、共用竖线：上面价格线（槽 0、线宽 1.5），下面成交额柱（`#C9C1B4`）；来源切换、代码变更、拆合股画成灰色虚线，
  标签等宽 10.5px。
- 坑：`inside` 的 dataZoom 会挡住页面滚动，所以不做缩放、用区间预设；带 `width` + `overflow: "truncate"` 的轴标签点不到，点击挂在系列上。

## 动效

- 缓动：`--ease-gentle`（0.25, 0.1, 0.25, 1）给悬停的小位移，`--ease-out-soft`（0, 0, 0.2, 1）给入场；时长 `--duration-fast` 200ms
  （悬停、变色）、`--duration-slow` 600ms（入场）。
- 入场：`.fade-up`（上移 20px 淡入，600ms）给标题、筛选行、卡片；`.slide-left`（从左 20px 滑入，500ms）给列表行，每行错开 45ms、
  最多错开 12 行；`.line-grow` 给标题下的分隔线（宽度 0 → 100%）。`reveal()` 隔两帧加 `.visible`。
- 只在换页时播：同一视图重画（排序、开关、换区间）时 body 带 `.still`，直接显示。
- 悬停：行和导航右移 4px，导航透明度 0.65 → 1，品牌降到 0.6，"→" 淡入，pill 填色，都是 200ms；下拉列表展开时淡入并下落 4px。
- `prefers-reduced-motion` 时所有过渡 0.01ms。
- Personal-Web 的自定义光标、照片 scale-fade、换页淡出淡入没有搬过来。

## 交互

- hash 路由（`#/`、`#/g/<策略>`、`#/s/<run id>`、`#/compare`、`#/run`、`#/data`、`#/a/<代码>`），换页回到顶部；导航当前项加粗，
  `compare` 后面用等宽灰字标已选个数。
- 偏好存 localStorage（`qs.` 前缀：ui、selection、form、job、recent），只在本浏览器；读写都包 try/catch，没有也能用。
- 异步结果（搜索、换基准、检查标的池）按序号丢掉过期的；等待时在 note 行写"正在计算 …""检查中…"。
- 删除这类操作在原处二次确认（"确认删除 · 取消"），不弹窗。

## 新页面 / 新图表检查单
